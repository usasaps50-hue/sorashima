# 空島 SORASHIMA

ブラウザで遊べる 3D アクション RPG。パソコンでもスマホでも遊べます。

## 遊び方

- **パソコン**：`index.html` をブラウザで開く（ダブルクリックでも OK）
- **スマホ・URL から**：GitHub Pages で公開した URL を開く

## 操作

| パソコン | スマホ | 動作 |
|---|---|---|
| W A S D / 矢印 | 左のスティック | 移動 |
| スペース | ▲ ボタン | ジャンプ |
| クリック / F | ⚔ ボタン・画面をタップ | 攻撃・アイテムを使う |
| 1〜8 | アイテム欄をタップ | 持ち物の切り替え |
| Q / E / R | Q・E・R ボタン | 魔剣の技 |
| ドラッグ | 画面をドラッグ | カメラを回す |
| ホイール | 2 本指でピンチ | ズーム |
| M | 右上の地図をタップ | 地図を拡大 |
| B | （メニューに戻る） | 星の祭壇に戻る |

## 開発

```bash
npm install
npm run build   # js/ を build/game.js にまとめる
```

`js/` を編集したら `npm run build` を実行してから公開してください。
