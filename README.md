# 空島 SORASHIMA

ブラウザで遊べる 3D アクション RPG。パソコンでもスマホでも遊べます。

## 遊び方

- **パソコン**：`index.html` をブラウザで開く（ダブルクリックでも OK）
- **スマホ・URL から**：GitHub Pages で公開した URL を開く

## 操作

| パソコン | スマホ | 動作 |
|---|---|---|
| W A S D / 矢印 | 左のスティック | 移動 |
| スペース | ▲ ボタン | ジャンプ |
| Shift + 移動 | スティックを端まで倒す | 走る |
| クリック / F | ⚔ ボタン・画面をタップ | 攻撃・アイテムを使う |
| 1〜9・0 | アイテム欄をタップ | 持ち物の切り替え（同じマスをもう一度で素手） |
| Q / E / R | Q・E・R ボタン | 魔剣の技 |
| クリック / F（柵・扉を持って） | ⚔ ボタン | 柵・扉を建てる |
| R / T（柵・扉を持って） | ⟳・木 ボタン | 向きを回す / 木材を選ぶ |
| V（柵・壁を持って） | 囲 ボタン | 囲うモード：角を 2 つ選んで四角く囲う |
| G | 「開ける」ボタン | 門扉を開け閉め |
| P | 🐾 ボタン | ペットと牧場の一覧 |
| ドラッグ | 画面をドラッグ | カメラを回す |
| ホイール | 2 本指でピンチ | ズーム |
| M | 右上の地図をタップ | 地図を拡大 |
| B | （メニューに戻る） | 拠点（なければ星の祭壇）に戻る |

## シロクマを仲間にする

1. 白嶺の雪原を歩くと、たまにシロクマ（親だけ、または親子）が現れる
2. 木のわなを置き、クマを攻撃して怒らせる（子グマを叩くと親も怒る）
3. わなの踏み板まで誘いこむと、檻が落ちて閉じこめられる（約 40 秒で壊して出てくる）
4. 生肉を持って近づき、あげると仲間になる
5. 柵や壁で囲った中に「拠点の旗」を立てると牧場になる。P キーの一覧から「休ませる」（親は 2 枠、子は 1 枠。40㎡ ごとに 1 枠）

## 開発

```bash
npm install
npm run build   # js/ を build/game.js にまとめる
```

`js/` を編集したら `npm run build` を実行してから公開してください。
